# 安装

从零装到 agent 能来玩。每一步出了问题，先看这一步下面的「看对没对」。

各部分的关系：

```
游戏 + 插件（plugin/）
   │  读写文件：chat-service/data/
   ▼
聊天服务（chat-service/，127.0.0.1:8740）── 聊天面板（panel/，或者 Steam 覆盖层里的网页）
   ▲
   │  agent 来玩的路，选一条（见 docs/连接.md）
   ├─ 命令行工具 tools/vp_player.py（能跑命令的 agent，比如 Claude Code）
   ├─ Ludus hub（mcp-hub/，127.0.0.1:8741/mcp）：MCP 客户端、只能读写文件的客户端（文字信箱）
   └─ Claude Code 的 channel（claude-code-channel/）：把面板上的话推进终端里的 claude
```

## 要准备的

| 要什么 | 干什么用 | 没有会怎样 |
|---|---|---|
| Windows 10 / 11 | 游戏和插件只在 Windows 上 | — |
| Steam 版《火山的女儿》（appid 1669980） | 插件按这一版的游戏代码写 | — |
| [BepInEx 5](https://github.com/BepInEx/BepInEx/releases)，x64 版（5.4.23 或更新的 5.x） | 把插件加载进游戏 | 插件加载不了 |
| Visual Studio 2022，或者免费的「Build Tools for Visual Studio 2022」（勾「.NET 桌面生成工具」） | 编插件（用里面的 Roslyn `csc.exe`） | 编不了插件 |
| [Node.js](https://nodejs.org/) 22.12 或更新，`node` 在 PATH 上 | 聊天服务、面板、hub、channel（最低版本卡在面板：Electron 44 装的时候要 22.12；hub、channel 用的 MCP SDK 要 20 以上） | 都起不来 |
| [Python](https://www.python.org/) 3.10 或更新，`python` 在 PATH 上 | `tools/vp_player.py` 等，只用标准库 | agent 玩不了 |
| [uv](https://docs.astral.sh/uv/)（可选） | `tools/mark_shot.py` 在截图上画按钮编号（借 `uv run` 装 Pillow） | 截图上没有编号，工具照样给原图 |
| [FFmpeg](https://ffmpeg.org/)（可选），`ffmpeg` 在 PATH 上 | hub 和 channel 把大截图缩小、转成 JPEG 再发给客户端 | 发原图；太大的只给路径 |
| agent 用的客户端 | Claude Code、Claude 桌面 app、别的 MCP 客户端…… | 见 `docs/连接.md` |

`python`、`ffmpeg` 不在 PATH 上也行：hub 和 channel 用环境变量 `LUDUS_PYTHON`、`LUDUS_FFMPEG` 指到完整路径（hub 也可以用参数 `--python`、`--ffmpeg`）。

## 零、先备份存档

agent 自己玩的时候，游戏每次换月都会照常自动存档（存进 0 号存档位），会盖掉那一格原来的东西。装之前、每次让 agent 开新的一局之前，先备份。

- 存档在 `%USERPROFILE%\AppData\LocalLow\EggHatcher\VolcanoPrincess\`：`ArchiveSaveN.sav` 是存档位：一共 24 格（读档界面一页 8 格、3 页），`ArchiveSave0.sav` 是自动存档，其余的 N 就是读档界面上的「Save N」，没存过的格子没有文件；`CommonArchive0.sav` 是跨存档的公共记录（收藏室、成就、继承天赋、排行榜，还有读档界面上每一格的摘要）。
- 备份：游戏关着时，把整个文件夹拷一份。
- 还原：游戏关着时拷回去。只还原 `ArchiveSaveN.sav` 的话，读档界面的摘要（女儿是谁、几岁、哪年哪月）还是旧的，因为它记在 `CommonArchive0.sav` 里，要连它一起还原。开着 Steam 云同步的话，Steam 可能提示存档冲突，选本机的那一份。

## 一、拿到代码

把仓库放在一个路径里没有 `&`、`%`、`!` 的文件夹（cmd 的 .bat 对这几个字符不稳）。下面的命令都在仓库根目录跑，`<仓库>` 指这个文件夹。

### 命令怎么敲：cmd 和 PowerShell

Windows 自带两种命令行，有几处写法不一样。下面的说明两种都写；没写的就是两边一样。

| 要做的 | cmd | PowerShell |
|---|---|---|
| 给这个窗口设一个环境变量 | `set GAME=C:\游戏文件夹` | `$env:GAME = 'C:\游戏文件夹'` |
| 跑一个 .bat | `plugin\build.bat` | `.\plugin\build.bat` |
| 装 Node 的依赖 | `npm.cmd install` | `npm.cmd install` |

- `set` / `$env:` 只管这个窗口和从这个窗口里起的程序，关了窗口就没了。想一直有效用 `setx`（两边写法一样，见第五节），设完新开的窗口才有。
- `npm` 一律写成 `npm.cmd`：PowerShell 默认的执行策略不让跑脚本，直接敲 `npm` 会跑到 `npm.ps1`，被拦下（「在此系统上禁止运行脚本」）。写 `npm.cmd` 两边都能用，不用改执行策略。
- 能双击的 `.bat`（`chat-service\start-server.bat`、`mcp-hub\start-hub.bat`、`panel\start.bat`、`claude-code-channel\start-claude.bat`）双击就行，不用开命令行。

## 二、装 BepInEx 5

1. 找到游戏文件夹：Steam 里右键火山的女儿 → 管理 → 浏览本地文件。默认在 `C:\Program Files (x86)\Steam\steamapps\common\VolcanoPrincess`。
2. 下载 BepInEx 5 的 `BepInEx_win_x64_5.4.23.x.zip`，解压到游戏文件夹里（解压后游戏的 exe 旁边多了 `winhttp.dll`、`doorstop_config.ini` 和 `BepInEx\` 文件夹）。
3. 从 Steam 启动一次游戏，到标题画面就关掉。BepInEx 这时建好 `BepInEx\plugins\`、`BepInEx\config\`。

看对没对：游戏文件夹里有 `BepInEx\core\BepInEx.dll` 和 `BepInEx\LogOutput.log`。

## 三、编插件、装进游戏

**先后顺序：先在游戏里装好 BepInEx 5，从 Steam 启动一次游戏到标题画面（第二节），再编。** 编的时候要用游戏里 `BepInEx\core\` 的 dll。

> **`build.bat` 编完默认直接装进游戏**：把 dll 复制到游戏的 `BepInEx\plugins\LudusLunae\`，换掉那里原来的那一份。只想编译、不碰游戏，先设 `NOINSTALL=1`（cmd：`set NOINSTALL=1`；PowerShell：`$env:NOINSTALL = '1'`）。

插件有两版，装一个就行：

- `plugin/`（推荐）：文字为主，第一次见到的人、地方、CG、怪物会截图给 agent 看；战斗写成文字、能交给队友打；印象簿、回音、「上回说到」。
- `plugin-text-only/plugin/`：只用文字的老版本（0.3.7），给用的模型看不了图、或者只想用文字玩的人：不会自动给图，`shot` 照样能截整屏。它配自己的老工具 `plugin-text-only/tools/vp_player.py`，用法见 `plugin-text-only/README.md`。

编（这是图像版；纯文字版把 `plugin\build.bat` 换成 `plugin-text-only\plugin\build.bat`，设置都一样）：

cmd：

```bat
set GAME=C:\Program Files (x86)\Steam\steamapps\common\VolcanoPrincess
plugin\build.bat
```

PowerShell：

```powershell
$env:GAME = 'C:\Program Files (x86)\Steam\steamapps\common\VolcanoPrincess'
.\plugin\build.bat
```

- `GAME` 是游戏文件夹。装在默认位置可以不设。
- `build.bat` 自己用 vswhere 找 Visual Studio 的 `csc.exe`；找不到就设 `CSC` 为 `csc.exe` 的完整路径（在 `<VS 或 Build Tools 的安装位置>\MSBuild\Current\Bin\Roslyn\csc.exe`）。
- 不想每次都设：在 `plugin\` 里建一个 `build.local.bat`，写上这几行 `set GAME=…`、`set CSC=…`，build.bat 每次会先读它（这个文件不进 git）。它是 .bat，在哪种命令行里跑 build.bat 都用 cmd 的 `set` 写。
- 换输出位置：设 `OUT` 为一个文件夹。
- **游戏里还没装 BepInEx 也想先编**：把 BepInEx 5 的 zip 另外解压到一个文件夹，设 `BEPINEX_CORE` 为里面的 `BepInEx\core` 文件夹（cmd：`set BEPINEX_CORE=D:\下载\BepInEx\BepInEx\core`；PowerShell：`$env:BEPINEX_CORE = 'D:\下载\BepInEx\BepInEx\core'`）。这时游戏里没有 BepInEx，build.bat 编完不往游戏里复制，只说一声；在游戏里装好 BepInEx、启动一次以后再编一次，就装进去了。
- 改了插件源码要重编，再重开游戏。

插件和聊天服务之间靠文件说话，文件都在聊天服务的 data 文件夹（默认 `<仓库>\chat-service\data`）。build.bat 把这个路径编进插件当默认值；仓库挪了位置、或者想用别的 data 文件夹，有两种改法：重编之前设 `DATA_DIR`（cmd：`set DATA_DIR=…`；PowerShell：`$env:DATA_DIR = '…'`）；或者改游戏里的 `BepInEx\config\ludus-lunae.volcano-princess.cfg` 的 `DataDir`（第一次启动后才有这个文件，改完重开游戏）。这个配置文件里还有两个玩法上的参数：每句台词停多久、画面多久不变算轮到 agent。

看对没对：启动游戏，`BepInEx\LogOutput.log` 里有「Ludus Lunae 已加载，数据文件夹：…」，路径是你的 `chat-service\data`。

## 四、起聊天服务

双击 `chat-service\start-server.bat`（或者 `cd chat-service` 再 `node server.mjs --hub`）。关窗口就停。

- 只听本机 `127.0.0.1:8740`。第一次启动会在 `chat-service\data\` 下建 `token`（本机各组件之间用的口令：`say.mjs`、hub、channel、面板自己读它，你不用配）和 `modes.json`（面板上的开关，跳过小游戏默认开着，见第七节）；聊天记录、谁在线、面板的位置都记在这个文件夹里。
- `--hub` 顺手在后台起 Ludus hub（MCP 服务，`127.0.0.1:8741`），已经开着就不起；hub 单独跑，关掉聊天服务的窗口它不停。hub 第一次要装依赖：先双击一次 `mcp-hub\start-hub.bat`（它会自己 `npm.cmd install`，装完起在这个窗口里，关掉就行）。不用 hub 的话（比如只用 channel 或命令行），去掉 `--hub`：在 `chat-service\` 里跑 `node server.mjs`。
- 端口被占了：设 `LUDUS_PORT` 换聊天服务的端口（cmd：`set LUDUS_PORT=8750`；PowerShell：`$env:LUDUS_PORT = '8750'`；在同一个窗口里再起聊天服务。双击 bat 要用的话 `setx`）。换了的话，所有组件都要设成一样（见 `docs/连接.md`「可以自己改的地方」）。

看对没对：浏览器打开 `http://127.0.0.1:8740/`，能看到聊天页。

## 五、名字

agent 看到的说明里，你叫什么、agent 的默认名字叫什么，都来自两个环境变量：

| 环境变量 | 是什么 | 默认 |
|---|---|---|
| `LUDUS_USER_NAME` | 你的名字：agent 看到的「user 在面板上说」「对 user 说一句话」、面板上你自己的气泡 | `user` |
| `LUDUS_AGENT_NAME` | agent 的默认名字：Claude Code 里跑命令行（vp_player）、channel 时，没报名字的会话叫「agent（终端）」（桌面 app 里的 Claude Code 跑命令行叫「agent（桌面 app）」）；给 stdio 小桥设了它，Claude 桌面 app 连 hub 时也用它（下面）；面板上的按钮「agent 自己玩」 | `agent` |

聊天服务、hub、channel、vp_player 都读这两个，所以设成用户级的环境变量最省事（cmd 和 PowerShell 里都这样写）：

```bat
setx LUDUS_USER_NAME 小雨
setx LUDUS_AGENT_NAME 月
```

`setx` 只对之后新开的窗口和程序有效：设完重开终端，重启聊天服务、hub，完全退出再打开 agent 的客户端。

连 hub 的 MCP 会话不一样：不报名字时叫「hub：客户端名」。Claude Code 是「hub：claude-code」；Claude 桌面 app（经 stdio 小桥）是「hub：claude-ai」，在桌面 app 的 MCP 配置里给小桥写上 `"env": { "LUDUS_AGENT_NAME": "月" }` 就是「hub：月」（`docs/连接.md` 第三节）。

agent 每次来也可以自己报名字（`hello 名字`，连 hub 的是 `play hello 名字`），面板上、印象簿都按这个名字分。见 `docs/记忆.md`。

## 六、打开「一个玩家一个文件夹」

**只有图像版（`plugin/`）要跑这一步。** 纯文字版（`plugin-text-only/`）的插件和它配的老工具不认玩家文件夹：用纯文字版时别跑，别建 `selfplay\players.json`。

一个 agent 的印象簿、截图、说过的话、游戏记录放在它自己的文件夹里，几个 agent 轮流来玩也不会串（`docs/记忆.md`）。开关是 `chat-service\data\selfplay\players.json`：在就按玩家分，不在就都放在 `selfplay\` 下一份。新装的建议打开：

```bat
python -X utf8 tools\migrate_players.py --go
```

游戏关着的时候跑。对空的 data 文件夹也能跑，只建 `players.json` 和 `active.json`。以前用单文件夹布局玩过、要把旧东西搬给某个玩家，先不加 `--go` 看它打算怎么搬，参数见 `python -X utf8 tools\migrate_players.py -h`。

## 七、聊天面板

两种，挑一种：

- **Electron 面板**（`panel/`）：无边框、置顶的小窗，放在游戏旁边。双击 `panel\start.bat`：第一次会自己装 Electron（`npm.cmd install`，没下到 Electron 本体就补跑 `node node_modules/electron/install.js`），之后直接开。
- **Steam 覆盖层里的网页**：游戏里 Shift+Tab → 网页浏览器 → 地址 `127.0.0.1:8740`，点图钉钉在画面上。钉住的窗口只能看、不能打字，要说话得再 Shift+Tab。

面板只在游戏开着、而且有 agent 挂着的时候出来；想先看一眼，点托盘里的月牙图标。热键、收起、透明度见 `panel/README.md`。

面板顶上三个开关：

- **agent 自己玩**：开着是 agent 玩（插件替它翻对话、点按钮，停在要做决定的地方）；关着是你自己玩，插件把台词和选项一段段发给 agent（陪玩）。
- **边玩边聊**：你自己玩时，离开一个地方、或者一段长剧情播完，就把刚才那段台词送给 agent；关掉就只在月底一起送。只有 channel 接上的 agent 收得到（`docs/连接.md`「几种接法差在哪」）。
- **跳过小游戏**：默认开着，跳过限时、靠手速的小游戏（用 agent 一步一步点来不及），直接给最好的结果。想自己玩，在面板上关掉这个开关，或者让 agent `skip off`。谁玩都能开关。

## 八、让 agent 来玩

hub 是一个普通的 MCP 服务器：hub 开着时，在你的 agent 用的客户端里加一个 HTTP 的 MCP 服务器 `http://127.0.0.1:8741/mcp`，新开一个会话，让它先 `wait`。只认 stdio 的客户端用 `mcp-hub\stdio-bridge.mjs` 转一下。详细的在 `docs/连接.md` 第一节。

只走 MCP 的客户端，agent 只在调用工具时才捎得到你在面板上说的话；它停下来以后，要在它的客户端里叫它。

给 Claude 家的客户端写好了现成的做法（Claude Code 的命令和 channel、Claude 桌面 app 的小桥、claude.ai 的文字信箱），见 `docs/连接.md` 第二到四节、第七节。

agent 自己玩：面板上打开「agent 自己玩」，在游戏里读档或开新游戏，让 agent `wait`。一起玩：开关关着，你自己玩，agent 在旁边看（channel 会把一段段台词推给它；连 MCP 的 agent 收不到台词，想看画面就 `shot`，想翻面板上的话就 `panel`）。几种接法的差别见 `docs/连接.md`「几种接法差在哪」。

同一时间只让一个 agent 在玩：`hello` 就是接手，之前那个歇着。

## 十、成就、卸载

- **成就**：agent 正常玩出来的成就和你自己玩的一样算。跳过小游戏默认开着：跳过一个小游戏时，从跳过开始到它结算完，插件把这期间的成就挡下（本地也不记），事件里写「[挡下成就]」。想让小游戏里的成就照常算，就关掉跳过小游戏（面板上的开关，或者 `skip off`）自己玩。小游戏多给的金币、声望会算进累计数，之后可能因此早一点拿到累计类成就，这种分辨不出来。
- **只卸这个插件**：删掉游戏里的 `BepInEx\plugins\LudusLunae\`。
- **连 BepInEx 一起卸**：删掉游戏文件夹里的 `winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`changelog.txt` 和 `BepInEx\`。游戏自己的文件没动过。
- 聊天记录、截图、印象簿都在 `chat-service\data\`，不要了就删这个文件夹。

## 常见问题

- **vp_player 说游戏没开**：插件写的 `chat-service\data\selfplay\state.json` 20 秒没更新就算没开。看 BepInEx 的日志里插件加载了没有、数据文件夹对不对。
- **命令 30 秒没回应**：游戏没焦点时会自己暂停。插件在「agent 自己玩」开着、或者有 agent 挂着时让游戏在后台照常跑；都不是的时候，点一下游戏窗口。
- **「selfplay 关着」**：面板上没开「agent 自己玩」。关着的时候插件只接 `shot`（只截画面）和 `hello`。
- **「某某接手了，你先歇着」**：别的 agent 在玩。要接回来就 `hello`。
- **端口被占**：聊天服务 `LUDUS_PORT`，hub `--port` 或 `LUDUS_HUB_PORT`。换了要所有组件一起换。
